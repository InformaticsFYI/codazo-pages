Install

From Obsidian's community plugins.

Codazo is listed in Obsidian's community plugin directory. Obsidian desktop 1.11.5 or newer is required; mobile is not supported yet.

  1. In Obsidian, open Settings › Community plugins. If this is your first community plugin, turn off Restricted mode.
  2. Choose Browse, search for Codazo, and select Install. Or open Codazo directly in Obsidian.
  3. Select Enable, then open Settings › Codazo to add a provider profile.

The directory page shows the current version. Prefer to install by hand? Each GitHub release carries main.js, manifest.json, and styles.css with SHA-256 checksums; put them in .obsidian/plugins/codazo/. The repository holds the readable source and the same unminified main.js, so you can build it yourself with npm ci && npm run build.

Configure a provider profile

Open Settings › Codazo and create a profile. You can keep several and pick the active one.

ServiceEndpointNotes
OpenAIhttps://api.openai.com/v1Fixed. Works with json_object.
Ollama Cloudhttps://ollama.com/v1Fixed. Hosted inference, not local. Use the exact model tag.
Personalizadoany OpenAI-compatible base URLOpenRouter, a local server, and so on. HTTPS, or plain HTTP only to localhost, a .local name, or a private-network address.

The key is sent only to that profile's destination, never to Codazo. Store it for the session, or on this device through Obsidian's Secret Storage; there is no plaintext fallback. Changing a profile's destination asks for a new key. Deleting a profile deletes its key.

Local models

A local server such as LM Studio works with a custom profile, with three settings that matter:

  • Formato de respuesta: json_schema. Local servers usually reject json_object, and instructions alone let small models drift off the contract.
  • Campo de límite de tokens: max_tokens.
  • Tiempo máximo de espera: raise it; a local model may take a minute or two.

Prefer models that answer directly. Reasoning models spend their whole budget thinking and often never produce the JSON inside the timeout. In a check against LM Studio, a small non-reasoning model satisfied the contract in json_schema mode; a 30-billion-parameter reasoning model never answered. Any model, local or hosted, can still break the contract; when it does, the notice names the field or rule it broke.

Your Codazo folder

Saved notes go under the folder set in settings, Codazo by default:

SubfolderHolds
ReviewsSaved reviews, with the exact source and a reloadable payload.
StudyStudy sheets, also reloadable.
ExtractosExcerpts of text you are reading, always saved.
RevisionsYour own revision notes, created on request.
Palabras and VerbosOne note per word and per verb-and-tense, with a codazo-progreso property.
ExportsJSON and HTML exports.

Files are never overwritten; a name collision gets a new name, and word and verb notes that already exist are left alone.

Other settings

  • Interface language: Spanish (default) or English, for the plugin's own text only.
  • Pane sections start open: summary, observations, words, and verbs are collapsible; choose whether they begin open or closed.
  • Save reviews automatically and Create word and verb notes automatically: both off by default.
